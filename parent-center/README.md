# PlanYourTV 中文家长中心（独立增强版）

一个**独立、离线、单文件**的家长中心网页，参考「学习锁 · 局域网家长控制端」的交互与视觉，面向 [PlanYourTV](https://github.com/heimi51168/planyourtv) 用户。它不修改电视 APK、不连接电视，所有设置与题库都保存在你自己的浏览器里，可用于配置参考、题库整理与备份。

## 功能

- **自定义设置**：每轮观看时长、弹题数量、答错等待、鼓励方式、严格模式、答题暂停播放、一二年级注音、题目朗读、护眼休息、按时段生效（含星期）、家长密码。改动即时存入 `localStorage`，可导出/导入 JSON 配置。
- **双格式题库，上传自动识别**：
  - 学习锁 `.zip`：内含 `s/o/a/e` 的 json，支持 `index.json` 一次带多个包；
  - PlanYourTV 原生 `.json/.txt`：`question/options/answer/answerIndices`，支持单选 + 多选（如 `answer: "A、C"` 或 `answerIndices: [0,2]`）。
- **题库管理**：按包启用/停用、删除、清空；题目浏览、按包/题型/关键词筛选、分页；答案与解析预览。
- **备份导出**：一键导出「学习锁 zip」（标准格式，可再导入学习锁体系）或 JSON。
- **零依赖**：纯 HTML + 原生 JS，ZIP 读写自行实现，IndexedDB 存题库，无外部 CDN、无网络请求。
- 亮/暗主题切换，桌面与手机自适应。

## 使用

用**新版浏览器**（Chrome / Edge / Firefox，需支持 `DecompressionStream('deflate-raw')`，2023 年后的版本均可）直接双击打开 `parent-center.html` 即可，无需服务器、无需联网。

1. 在「自定义设置」里调整参数，改动自动保存；需要留底时点「导出配置 JSON」。
2. 在「学习题库」区点击或拖入题库文件（可多选 `.zip/.json/.txt`），系统自动识别格式并解析。
3. 在「题库包 / 题目浏览」标签查看、启停、筛选题目。
4. 点「导出全部备份（学习锁 zip）」把题库打包留底或迁移。

> 题库与设置保存在当前浏览器。清除浏览器数据会一并删除，请定期导出备份。

## 题库格式

网页内「格式说明」标签有完整示例。核心字段：

| 格式 | 题干 | 选项 | 答案 | 解析 |
|---|---|---|---|---|
| 学习锁 | `s` | `o` | `a`（0 起算下标） | `e` |
| PlanYourTV | `question` | `options` | `answer:"A"` / `answerIndices:[0,2]` | `explanation` |

两种格式的题目都会归一化成统一结构：单选/多选自动判定，导出时可还原为任一格式。

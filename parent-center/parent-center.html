【学习锁 zip 格式】 zip 内直接放 json（不要套文件夹）。无 index.json 时每个 json 是一个包： math.json → {"items":[{"s":"1+1=?","o":["1","2","3","4"],"a":1,"e":"因为 1+1=2"}]} 有 index.json 时可带多个包、中文名、启停： {"packs":[{"id":"math","title":"三年级数学","grade":3,"subject":1,"enabled":true}]} 【PlanYourTV 原生格式】 json / txt 均可，题干字段 question，选项 options，解析 explanation： {"items":[{"question":"1+1=?","options":["1","2","3","4"],"answer":"B","explanation":"..."}]} · 单选答案可写 "B" 或 "1"（0 起算）或 answerIndex:1 · 多选答案可写 "A、C" 或 answerIndices:[0,2]，type 填 "multiple" · 也接受直接粘贴的题目数组 [ {...}, {...} ] 字段会自动归一化成统一题目卡，导出时两种格式都能还原。
